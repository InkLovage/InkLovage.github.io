  • 错一题扣一分，就是“损失函数”。
  • 让损失函数更小，就是机器学习的方向。

数据——机器学习的燃料

数据的基本含义

数据其实是一组个体（样本，example / sample）所具有的特征与结果。

数据一般遵循独立同分布（independently and identically distributed，i.i.d.），但这并非必要条件。样本有时也叫作数据点（data point）或数据实例（data instance）。

  • 独立分布——也即数据之间没有影响关系。

样本

  • 定义
  • 特征
  • 标签

数据集（dataset）

  • 定义
  • 训练集
  • 验证集
  • 测试集

数据的维度

  • 数据需要用数学方式表示，例如矩阵、张量和线性代数等。因为计算机只认识 0 和 1，所以有了数据维度的概念。
  • 每个样本的特征量一致时，就形成了一个固定维度的数据集。
  • 数据集形状 = 样本数 × 特征维度。

数据的质量比数据的数量重要

  • 标签错误 → 模型会学错。
  • 特征冗余或无意义 → 增加训练难度。
  • 样本偏差 → 导致训练出来的模型只适用于少数人。

数据不代表现实世界全部

  • 如果数据代表的只是“过去的策略”或“片面的历史经验”，模型可能会强化旧偏见。

数据科学

  • 数据的收集、预处理、使用、验证和测试等构成了一个庞大的知识体系，统称为数据科学。
  • 预处理

模型——一种映射变换/函数

定义（笔者自己理解的定义）

  • 机器学习中用于将输入数据映射到输出结果的数学结构或计算规则。
  • 模型本质上是从输入到输出的一种转换关系（映射），例如：图像输入 → 情绪输出，传感器读数 → 正常或异常。
  • 模型可以很简单（线性模型），也可以非常复杂（神经网络）。

深度学习

  • 层层抽象 → 层层数据转化。

基本模型分类

  • 线性回归
  • 决策树
  • 支持向量机（SVM）
  • 随机森林
  • 卷积神经网络
  • 循环神经网络
  • Transformer（前馈神经网络）

模型的由来

  • 模型一开始是空的，参数是随机的。
  • 用“数据”教它什么输入对应什么输出。
  • 模型通过“调整自己”（优化参数），越来越接近我们想要的输出。

目标函数（损失函数）

笔者定义

  • 对模型优劣程度的度量，这个度量在大部分情况下是可优化的。

模型训练

  • 不断让损失函数值更低。

  • 错一点，罚一点；错得越多，罚得越多（平方惩罚）。

    常见目标函数之一是平方误差（squared error）：

    L = (1/n) × Σ(i=1→n) (yᵢ - ŷᵢ)²

  • 当训练具有“分类”用途的模型时，例如识别图片是猫还是狗：

    • 使用交叉熵损失函数（Cross Entropy Loss）。

    • 二分类问题使用二分类交叉熵衡量预测分布与真实标签分布之间的距离：

      L = -[y log(ŷ) + (1-y) log(1-ŷ)]

      其中，预测概率 ŷ ∈ (0, 1)，真实标签 y ∈ {0, 1}。

  • 过拟合

    • 一个模型在训练集上表现良好，但不能推广到测试集，这个模型被称为过拟合（overfitting）；模型的泛化（generalization）能力比较弱。
    • 防止过拟合

优化算法

笔者定义

  • 找到一组最优的模型参数，使得损失函数最小化。

梯度下降（Gradient Descent）是最常用、最核心的优化算法

  • 参数每次往“损失函数下降最快的方向”走一步，直到找到最低点。

  • 参数更新公式：

    w := w - η × ∂L(w)/∂w

  • 对于多元函数 L(w₁, w₂, …, wₙ)，各参数上的偏导数组成梯度向量：

    ∇L(w) = [∂L/∂w₁, ∂L/∂w₂, …, ∂L/∂wₙ]

    梯度指向函数增长最快的方向，因此沿负梯度方向更新参数。示例：若梯度为 [2, 1]，学习率 η = 0.1，则：

    w₁ := w₁ - 0.1 × 2 = w₁ - 0.2

    w₂ := w₂ - 0.1 × 1 = w₂ - 0.1

    每次沿这个方向走一点，就像“往谷底滑下去”。

  • 公式中各符号的含义：

    • ∂L(w)/∂w：损失函数对参数的梯度（偏导）。
    • η：学习率（learning rate），控制参数每一步“走多远”。
    • 学习率太大 → 容易跳过最低点，甚至发散。
    • 学习率太小 → 收敛很慢，训练时间长。

  • 通常动态调整学习率。
