20. 深度学习代码中的高频 Python 写法

20.1 标准训练循环

其中涉及的 Python 语法：

  • range(num_epochs)：生成 epoch 序列。
  • for ... in ...：迭代。
  • enumerate(train_loader)：同时得到批次编号和批次数据。
  • batch_index, (inputs, targets)：嵌套解包。
  • inputs.to(device)：调用对象方法。
  • model(inputs)：调用一个可调用对象。
  • loss.item()：调用方法取得 Python 数值。
  • f"..."：格式化字符串。

train()、to()、zero_grad()、backward() 和 step() 的具体行为属于 PyTorch API。

20.2 定义模型

需要识别：

  • class MLP(nn.Module)：继承。
  • __init__：初始化方法。
  • super().__init__()：初始化父类部分。
  • self.network = ...：保存实例属性。
  • nn.Sequential(...)：函数调用跨多行书写。
  • 最后一个参数后面的逗号是合法的，并便于增删代码。
  • x: torch.Tensor 和 -> torch.Tensor：类型注解。
