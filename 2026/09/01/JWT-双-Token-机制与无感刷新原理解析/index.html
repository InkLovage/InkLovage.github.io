JWT 双 Token 机制与无感刷新原理解析

在前后端分离项目中，我们经常会使用 JWT（JSON Web Token） 完成用户身份认证。

但是，如果只使用一个 Token，就会遇到一个非常典型的问题：

Token 的有效期到底应该设置多长？

设置得太长不安全，设置得太短用户又需要频繁重新登录。

为了解决这个矛盾，实际项目中通常会采用：

Access Token + Refresh Token 双 Token 机制

本文记录一下双 Token 的基本原理，以及前端如何利用 Refresh Token 实现 JWT 的“无感刷新”。
