HTML 基础学习笔记：从标签到 DOM、表单与 Vue 实战

本文是 HTML 入门阶段的学习笔记，目标是能够读懂网页结构，并为后续学习 CSS、JavaScript、Vue 3 打基础。示例既包含标准 HTML，也包含可以直接放到 Vue 官方演练场 App.vue 中的 Vue 模板。

一、HTML 是什么？

HTML（HyperText Markup Language，超文本标记语言）是一种用于描述网页内容和结构的标记语言，而非用于一般计算的编程语言。

前端三大基础技术分工：

技术 主要职责 例子
HTML 网页有什么（内容、结构、语义） 标题、段落、按钮、表单
CSS 网页长什么样（外观、布局） 颜色、间距、Flex、Grid
JavaScript 网页如何交互（行为、逻辑） 点击事件、动态更新、请求 API

Vue 3 建立在这些基础上，提供组件、响应式数据和模板等能力。

二、标签、元素、属性

1. 标签与元素

  • <p>：开始标签；</p>：结束标签。
  • Hello World!：元素的文本内容。
  • <p>Hello World!</p>：完整的 HTML 元素（element）。

元素可以嵌套：

ul 是无序列表，li 是列表项。

2. 常见标签速查

标签 作用
h1 ~ h6 不同层级的标题（按文档结构使用）
p 段落
a 超链接
ul / ol / li 无序列表 / 有序列表 / 列表项
div 无特定语义的块级通用容器
span 无特定语义的行内容器
strong 重要性强调
img 图片
button 按钮
input 输入控件

div 与 span 主要用来组织内容，本身不表示“文章”“导航”等具体语义。

3. HTML 属性

属性写在开始标签中，用于提供附加信息：

属性 主要用途
id 标识当前文档中的特定元素（应当唯一）
class 为一组元素设置类名，便于 CSS/JS 使用
href 链接目标
src 图片、脚本等资源地址
alt 图片的替代文字
type 输入框或按钮类型
placeholder 输入框为空时的提示文本
required 表单必填约束（布尔属性）
name 表单提交时的字段名称
value 表单控件的值或选项提交值

注意：input、img、meta 等属于 空元素（void elements），没有包裹内容的结束标签。Vue 模板中常写为 <input />，标准 HTML 中 <input> 即可。

三、标准 HTML 文档结构

结构 含义
<!DOCTYPE html> 声明使用现代 HTML 标准，避免浏览器进入怪异模式；不是普通元素
<html lang="zh-CN"> 文档根元素；lang 声明主要语言
<head> 文档元信息（编码、视口、标题、资源等）
<meta charset="UTF-8"> 指定字符编码
viewport 元信息 便于正确适配移动设备视口
<title> 浏览器标签页标题，不是正文标题
<body> 网页正文的主要内容

区别：<title> 决定浏览器标签页标题，<h1> 是网页正文中的一级标题。

<style> 可以包含 CSS；<script> 可以包含或引用 JavaScript。它们与负责文档结构的 HTML 配合工作。

四、语义化标签与页面组织

与全部使用 div 相比，语义化标签能更清楚地表达内容职责：

标签 语义
header 页面或区域的头部
nav 导航链接区域
main 文档的主要内容
section 具有独立主题的内容分区
article 相对独立、可单独理解的内容（如博客文章）
aside 与主要内容间接相关的补充区域
footer 页面或区域的尾部

锚点跳转：<a href="#about"> 会定位到当前文档中 id="about" 的元素附近。

语义 ≠ 视觉位置：aside 不会自动出现在右侧，section 不会自动带边框；布局由 CSS 控制。

五、HTML 嵌套与 DOM 树

1. 父子、兄弟、祖先、后代

简化元素树：

  • 父子元素：直接包含，例如内层 div 是按钮 A 的父元素。
  • 兄弟元素：直接父元素相同，例如 section 与按钮 B。
  • 祖先与后代：允许隔多层，例如 section 是按钮 A 的祖先，按钮 A 是它的后代。
  • 父元素一定是祖先元素；祖先元素不一定是直接父元素。

把按钮 B 移到 </section> 之前，就会改变它的父节点，使它成为 section 的直接子元素。

2. HTML 与 DOM 的区别

  • HTML：用标签编写的标记文本。
  • DOM（Document Object Model，文档对象模型）：浏览器为文档建立的对象结构，供 JavaScript 查询、修改节点等。

除了元素节点，DOM 还有文本节点、注释节点、文档节点等：

因此，DOM 节点数不等于 HTML 标签数；空格、换行有时也会形成文本节点。

JavaScript 可以使用 DOM API 操作页面：

  • getElementById()：按 id 查找元素。
  • textContent：读取或设置文本内容。
  • element.children：直接子元素集合。
  • element.childNodes：直接子节点集合（可能包含文本、注释）。

3. 嵌套关系对 CSS 的影响（预习）

前面的按钮 A 虽然与 section 隔着一个 div，仍会匹配 section button；按钮 B 在 section 外，两条规则都不匹配。

不要根据代码在视觉上的“上下位置”判断 CSS 是否匹配，要看 DOM 的包含关系。

还要遵守 HTML 元素的内容规则。例如，p 元素不能包含 div；浏览器可能会自动修正不合法嵌套，导致 DOM 与源码不一致。

六、HTML 表单与用户输入

1. 基础表单

  • form：组织一组可提交的表单控件。
  • action：原生表单提交目标地址。
  • method：HTTP 提交方法；常见为 get 或 post。
  • label for="user_email" 与 input id="user_email" 对应；点击标签可聚焦对应输入框。
  • required：浏览器进行基础必填检查，但后端仍要重新验证。

原生表单默认编码不是 JSON；Django 接收传统 POST 表单字段时通常可以通过 request.POST.get('email') 获取。真实 Django POST 表单还需要正确处理 CSRF 保护。

2. id、name、value：最容易混淆的三个属性

属性 作用 此例
id 在文档中标识元素，供 label for、DOM 查询等使用 user_email
name 正常表单提交时的字段名 email
value 输入控件当前/初始值（具体行为随控件类型而异） a@example.com

3. 常见表单控件

写法 功能
<input type="text"> 单行文本
<input type="password"> 遮蔽显示输入字符（不是加密）
<input type="email"> 基本邮箱格式检查
<input type="number"> 数字输入控件
<input type="radio"> 单选项；同 name 的单选项属于一组
<input type="checkbox"> 复选项；可选多个
<select><option>...</option></select> 下拉菜单
<textarea></textarea> 多行文本
<button type="submit"> 提交表单
<button type="reset"> 重置表单控件到初始值
<button type="button"> 普通按钮，无默认提交行为

注意：在 form 内部，button 不写 type 时一般默认为提交按钮，因此推荐明确设置。

4. 下拉框中的 name 与 value

界面上显示“人工智能”，实际提交字段是 direction=ai。selected 可声明默认选中的选项。在 Vue 中通常改用 v-model 管理选中值。

5. 单选、复选和必填

对复选框使用 required，可要求它被选中后才通过浏览器的正常提交验证。

6. 前后端验证的边界

  • required：确保相应控件不为空（或单选/复选组符合基本约束）。
  • type="email"：仅检查基础格式，不能证明邮箱真实存在。
  • 两次密码是否一致：required 不会自动比较，需要 JS/Vue 逻辑与后端验证。
  • 密码：不能仅因使用 type="password" 就认为安全；生产环境应使用 HTTPS、服务端安全验证与密码哈希存储。
  • 原生表单 GET 会把字段编码到 URL 查询串中；密码等敏感数据不应该用 GET 提交。

九、常见易错点

  1. HTML 元素不等于标签：完整元素包含开始标签、内容和结束标签（空元素除外）。
  2. id 不等于 name：前者用于定位元素，后者主要是表单字段名。
  3. label for 对应 input id，不是 input name。
  4. section button 与 section > button 不同：前者选所有后代，后者只选直接子元素。
  5. button type="submit" 不等于已经实现登录：还需要提交处理及后端逻辑。
  6. required 不等于完整验证：后端必须重新验证。
  7. type="password" 不等于加密：它主要负责输入显示遮蔽。
  8. <title> 与 <h1> 不同：分别是标签页标题和正文标题。
  9. Vue 的 <template> 不是完整 HTML 文档：网页入口一般由 index.html 提供。
  10. 语义化标签不负责复杂布局：header、main、aside 的位置主要靠 CSS。

十、学习小结

完成 HTML 阶段后，应具备以下能力：

  • 能读懂网页的标签、属性和语义结构。
  • 能分析元素的父子、兄弟、祖先和后代关系。
  • 理解 HTML 与 DOM 的区别，知道 JS 可以通过 DOM API 操作页面。
  • 能编写包含 label、input、select、textarea 的基本表单。
  • 能理解 id、name、value 在前端与后端数据传递中的不同职责。
  • 能区分完整 HTML 文档与 Vue App.vue 组件。
  • 能独立用 HTML 搭出个人博客首页的基础骨架。

下一阶段：CSS，重点学习选择器、盒模型、Flexbox、Grid 和响应式布局，把已有的 HTML 结构变成真正可用的网页界面。
