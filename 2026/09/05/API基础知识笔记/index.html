API 基础知识

一、API 的定义

API（Application Programming Interface），即应用程序编程接口。

API 是软件对外提供的一组接口约定，使开发者能够调用已有功能，而无需了解其内部实现。

核心思想：封装实现，暴露接口。

二、API 的常见类型

1. 库与框架 API

例如：

  • C++：sort()
  • Python：math.sqrt()
  • Vue：ref()、reactive()

2. Web API

实现不同程序之间的网络通信。

例如：

GET /api/users/1

服务器返回 JSON：

三、HTTP 常见请求方法

方法 作用
GET 获取资源
POST 提交或创建资源
PUT 整体替换资源
PATCH 部分修改资源
DELETE 删除资源

四、Vue 中的 API

Options API： 使用 data、methods 等选项组织组件逻辑。

Composition API： 使用 ref()、computed() 等函数组织组件逻辑。

两者都属于 Vue 的编程接口，而不是网络通信接口。

五、总结

API 的本质是定义交互规则，隐藏内部实现。

API 不等于函数，也不等于 HTTP 请求。
